# 中国地貌底图渲染（分区配色 · 雪线林线 · 特有地貌 · 水体）

面向**中国境内线路**的底图渲染补充。通用原则仍在 `pitfalls-terrain.md`（§4 配色 / §5 冷白雪线 / §6 雪线取值），
本文件只写"中国特有的那部分"，两者冲突时**以通用原则为准**。

## 1. ⚠ 先说最重要的一条：色阶只能当"色序"，不能当"档位"

中国地貌资料里通行的分层设色是按**绝对高程**分档（0–200 绿、200–500 浅绿…5000+ 白）。
**这套数值不能直接抄进 `make_terrain.py`** —— 那正是 `pitfalls-terrain.md` §4 的头号坑：
`hypso()` 里 `np.clip(dem, stops[0], stops[-1])` 是静默的，色带走不出量程时不报错，
结果整图被 clip 进最低一档，"一片单色"（党岭 3200–5400 的档位搬到峨眉山 461–3104 就是这么翻的车）。

**正确用法**：把中国色阶当成**一串颜色的先后顺序**（色序），位置仍交给
`ramp_stops()` 按本区 p2–p99.7 归一化铺开：

- 换线路 → 色序不变、档位随分位漂移 → 永远不会"一片单色"；
- 需要雪色端时按 `SNOWLINE` 阈值（§5）判断，而不是按"5000 m"这个绝对数。

由此还顺带解决一个常见担心：**"青藏高原基底 4000 m，套通用色阶会整片深褐"** ——
在分位方案下**不会发生**，色带天然从本区 p2（高原上就是 4500 左右）开始铺。
"色阶整体上移"是给写死档位的老管线的补救手段，本技能不需要，也不该加。

## 2. 三大自然区 → 面要素染色目标色

`make_terrain.py` 的面要素用**乘法染色**（画进 `"L"` 掩膜 → 羽化 ≈10 逻辑 px → 乘到底图，
必须在合成矢量层之前做）。下表给的是染色**目标 RGB**，用法与 §4「林地/草坡乘法染色」一致。

| 暗针叶林（云冷杉） | 天山、横断山、喜马拉雅 | `#27500A` | (39,80,10) |

| 常绿阔叶 / 季雨林 | 华南、滇南、海南 | `#4E8C5A` | (78,140,90) |
| 典型草原 | 呼伦贝尔、锡林郭勒 | `#97C459` | (151,196,89) |

| 沙漠（沙丘） | 塔克拉玛干、巴丹吉林、腾格里 | `#EAD9A0` | (234,217,160) |

**戈壁色必须和沙漠色分开**（灰褐 vs 米黄）：戈壁是草原→沙漠的过渡带，
用同一色会让西北线路丢掉最重要的"干湿梯度"信息。

## 3. 中国色序（供 `_RAMP_ALPINE` / `_RAMP_SNOW` 参考）

按"低→高"排列，落地时只取**色序**与**相对间隔**，档位由 `ramp_stops()` 定：

```
滨海平原绿 #A8CE8A → 平原水网 #C2DCA6 → 丘陵农田 #CFD79B → 低山黄绿 #DCC98F
→ 中山黄褐 #D4B483 → 高中山褐 #C19A6B → 高山深褐 #B08558
→ 高寒草甸灰褐 #C2B3A5 → 高山寒漠灰白 #D8D4CE → 冰雪白 #F0F5FA
```

配色约束同 §5：**转白不能只提明度**，每档明度差 ≥20，否则高海拔糊成"雪盲"、
等高线数字也因底太浅读不出。

## 4. 雪线 / 林线分区取值表（换线路必查）

`SNOWLINE_LEVEL` / `SNOWLINE_LABEL` / `SNOWLINE_NOTE` 是**线路级常量**，每次换线路都要改
（当前 `make_terrain.py` 里残留的是珠峰线 `6000 m`，直接复用到别的山就是错的）。
取值查下表，多源交叉后再定，并把结论写进正文 `.snowline` 块 + 图例双色块。

| 山脉 | 现代雪线（m） | 备注 |
|---|---|---|
| 阿尔泰山 | 3000–3200 | 全国最低雪线之一 |
| 天山 | 3600–4400 | 北坡 3500–3900 / 南坡 3900–4200；伊犁河谷段 ≈3600（`pitfalls-terrain.md` §6 有夏塔段取值） |
| 祁连山 | 4300–5240 | 东段 4600–4700 < 西段 5000（降水差异） |
| 念青唐古拉山 | 4500–5700 | **东段 ≈4500、西段 5700**（季风降水差异）；东段南坡卡钦冰川 4890、阿扎冰川 4600，北坡比南坡高 200–400 m。东段南坡冰舌末端可低至 2530–3000 m（海洋型冰川），北坡末端 ≈4000 m |
| 横断山 | 4600–5500 | 海洋性冰川，雪线偏低 |
| 喀喇昆仑山 | 5100–5400 | |
| 冈底斯山 | 5800–6000 | |
| 喜马拉雅山 | 4300–6200 | **南坡 ≈4500、北坡 5900–6000**，差 1400 m 以上（雨影区） |

来源：国家统计局《中国冰川与雪线》。**纬度和海拔都不是决定项，降水才是** ——
喜马拉雅南坡（季风）比北坡低 1400 m，祁连山东段比西段低 300–400 m。
所以**绝不能写"雪线 = f(纬度)"的公式**，只能按山脉（必要时按坡向）查表。

**林线**（郁闭林上限）是独立于雪线的第二条阈值，横断山/喜马拉雅线路建议在图例里一起标：
天山 ≈2700、喜马拉雅 ≈4000、长白山岳桦上限 ≈2100。

⚠ 两条常见误判（沿用 §6）：
- **别把轨迹最高点当雪线**（南天山最高 4100 而雪线 3800 → 全程大部分在雪线**以下**，这结论对读者最有价值）；
- **无现代冰川的山不要给雪色端**：长白山（2744）、台湾山地只有季节性积雪，
  `_RAMP_SNOW` 不该启用（`SNOWLINE` 阈值判定会挡住，别手工打开）。

### ⚠ 雪线这个键会**切换整套配色**，不只是画一条虚线（2026-10-17 念青东实测）

`route_def.CFG['snowline_m']` 配不配，底图走的是**两套完全不同的色带逻辑**
（`make_terrain.hypso()` 内部分流）：

| | 判据 | 色带 | 观感 |
|---|---|---|---|
| 配了雪线，且 `dem_max ≥ snowline−250` | `belt_stops()` | **绝对高程地貌带**：森林→灌丛→草原→砾石→裸岩→季节性积雪→雪线以上积雪白，带位与雪线严格对齐 | 冷调、有明确的白雪区，喜马拉雅型线路同源 |
| 不配（或区域够不到雪线带） | `ramp_stops()` | **percentile 通用色带**：按本区 p2–p99.7 拉伸，色阶位置随高程分布漂移 | 暖调偏绿，`_RAMP_ALPINE` 还会刻意拉长绿段 |

**症状**：同一条技能出的两张图，一张"冷白有雪"、一张"绿褐一片"，用户会直接问
"技能是不是没同步"。**根因是雪线键没配**，脚本版本往往是一致的。
（念青东曲通C 最高 5275 m，够不到残留默认值 6000 m 的 `snowline−250`，于是回退通用色带。）

**所以**：只要本区有现代冰川（OSM `natural=glacier` 能抓到、或有冰川营地/地名），
就**必须**按上表配 `snowline_m` —— 顺带把配色切到正确的那套。
交叉验证办法：把窗口内冰川的**末端高程中位数**和**顶部高程中位数**算出来，
雪线落在这两者之间，再按积累区比率 0.5–0.6 取中值（念青东实测末端 4824 / 顶部 5156 → 取 5000）。

## 5. 进阶：把雪线锚进色带（可选）

默认实现里雪线与色带是**解耦**的：色带走分位，雪线由 `paint_snowline()` 单独画蓝线 + 注记。
这个解耦是对的，别合并。只有当你希望"色带转冷的位置 == 真雪线"时才做锚定：

1. 归一化位置 `t = (L − p2) / (p99.7 − p2)`，`L` = 本区雪线（§4 表）；
2. 把该位置设为"去饱和转冷"的锚点，雪线**下方 200–400 m 做渐变过渡**（遥感上雪线本身就是
   积雪覆盖率约 50% 的窄带，硬边必然失真）；
3. 若要做坡度修正（`slope < 35°` 才积雪），**只能在栅格上做**，不要拿矢量多边形去抠。

## 6. 中国特有地貌（OSM 多半没标签，漏了就不像中国）

| 地貌 | 区域 | 渲染办法 |
|---|---|---|
| **黄土塬梁峁沟壑** | 陕北、陇东、晋西 | OSM 无标签，靠 **DEM 坡度/曲率纹理**渲密集细沟，比任何多边形都真实 |
| **喀斯特峰林** | 桂、黔、滇东 | `natural=bare_rock` + `natural=peak` 点群，锥形符号 + 灰蓝底 |
| **石漠化** | 黔西南、滇东 | 灰白斑块嵌在绿色里，密度随坡度 |
| **雅丹** | 罗布泊、柴达木西 | 长条状定向纹理，方向与主风向一致 |
| **沙地 ≠ 沙漠** | 科尔沁、毛乌素、浑善达克 | 有植被覆盖 → **草原底 + 沙斑**，纯沙色严重失真 |
| **滩涂** | 江苏沿海、渤海湾 | `wetland=tidalflat`，浅灰蓝 + 潮沟纹理 |
| **红树林** | 海南、广西、福建 | `wetland=mangrove`，深绿锯齿边 |
| **梯田** | 哈尼、龙脊 | 等高线状细纹理，随等高线走向 |

## 7. 水体与湿地

| 要素 | 渲染 | RGB |
|---|---|---|
| 淡水湖（深 / 浅） | 按深度分色 | `#185FA5` / `#85B7EB` |
| **咸水湖 / 盐湖** | 浅青，别用淡水蓝 | `#7FC9C9` (127,201,201) |

| **浑浊河口** | 长江口 / 黄河口 / 钱塘江口近岸偏黄褐，比一刀切纯蓝真实 | `#C9A86A` |

## 8. OSM 标签 → 渲染映射

| 要素 | 标签 | 要点 |
|---|---|---|
| 现代冰川 | `natural=glacier`（way + relation） | 近白淡蓝填充 + **冰蓝边界**（边界必须可读，见 `pitfalls-terrain.md` §12）；高 zoom 加冰裂隙纹理 |
| 雪线以上裸岩 | `natural=bare_rock` / `scree` | 灰褐，与雪白之间留过渡带 |

| 草原 / 草甸 | `natural=grassland`（`heath` / `scrub`） | 典型黄绿 / 高寒橄榄 |

| 湿地 | `natural=wetland`（`marsh/swamp/bog/tidalflat/mangrove`） | 分类着色 |

| 河流 | `waterway=river/stream` | 按 stream order 分级线宽，casing+fill |

## 9. 数据源补充：OSM 在中国西部是稀疏的

东部城镇区 OSM 尚可，**羌塘、塔克拉玛干、昆仑这些无人区的 `natural` 面要素很稀疏**，
直接渲会出现"西部一片空白"。补数据的顺序：

| 用途 | 数据 |
|---|---|
| 土地覆盖（补西部） | ESA WorldCover 10 m（首选）/ **GlobeLand30 30 m（国产，国内分类更贴合）** |
| 冰川范围 | RGI 6.0 |
| 湖泊季节性 | JRC Global Surface Water |
| 河流分级 | OSM 国内大量缺 `width` → 用 **Strahler 分级**或 HydroRIVERS 的 `ORD_FLOW` |

做法：把栅格数据预处理成底图，OSM 矢量只叠加在其上做补充与注记。
水系名注记要用**沿河流走向的曲线注记**，山脉名沿山脊排列 —— 横排文字放在长江、
雅鲁藏布江上会立刻显得业余。

## 10. 合规（中国境内线路必读）

- **边界**：OSM 的中国行政边界（藏南、阿克赛钦、台湾等）**不符合标准画法**。
  攻略图若对外发布，底图边界要用自然资源部**标准地图服务**的画法，别直接沿用 OSM。
- **DEM**：公开可用 AW3D30 / Copernicus DEM（SRTM 在青藏高原有空洞）；
  **1:5 万等大比例尺 DEM 涉密**，不可用于对外产物。
- **瓦片**：批量下载第三方瓦片站属于违规（见 `pitfalls-terrain.md` §1），自渲染是正解。
